# : moon Growth Dashboard

Centro de mando para hacer de : moon shared living la plataforma líder de co-living en Europa.

## Stack Tecnológico

- **Frontend**: Next.js 16 + React 19 + Tailwind CSS
- **UI Components**: Radix UI + Custom components
- **Base de datos**: Supabase
- **CRM**: Brevo
- **Outreach**: Apollo.io
- **Scraping**: Apify
- **AI Content**: Claude Skills + Video AI

## Funcionalidades

### Overview
- Métricas clave en tiempo real
- Leads recientes
- Calendario de contenido
- Progreso hacia objetivos

### Leads Management
- Gestión de Anfitriones, Propietarios y Agencias
- Estados: Nuevo, Contactado, En Progreso, Convertido, Perdido

### Scrapers Automatizados
- Idealista, Fotocasa, Airbnb, LinkedIn

### Content Calendar
- Blog posts SEO
- Social media content
- Email sequences
- Video content

### Outreach Automation
- Secuencias de email (Apollo + Brevo)
- Seguimiento automático

### AI Content Studio
- Generación con Claude Skills
- Blog posts, Social media, Emails, Videos

## Configuración

```bash
npm install
cp .env.example .env.local
# Añade tus API keys
npm run dev
```

Abrir http://localhost:3000
